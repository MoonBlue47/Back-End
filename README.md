# ☕ Formação Backend Java: Fundamentos
Repositório destinado ao registro, versionamento e consolidação dos exercícios práticos desenvolvidos durante o curso de Backend em Java, cobrindo desde a sintaxe inicial até algoritmos e estruturas de dados fundamentais. </p>

---

## 📌 Sobre o Projeto
Este projeto centraliza o código produzido ao longo do treinamento prático de lógica e fundamentos com a linguagem Java. O objetivo é registrar a evolução contínua, organizar as práticas de sintaxe limpa e servir como guia de referência 
rápida para estruturas essenciais da linguagem.

# 🚀 Destaque dos Desafios
## 💼 Desafio 01: Cálculo de Reajuste Salarial
* Objetivo: Simular um sistema de folha de pagamento que ajusta salários com percentuais progressivos baseados em faixas de rendimento.
* Técnicas: Entrada via Scanner, operadores relacionais e formatação de casas decimais com printf.
## 🏫 Desafio 02: Gestão de Mensalidades com Descontos Progressivos
* Objetivo: Calcular o valor final de uma mensalidade de acordo com a categoria selecionada via menu e a data de pagamento realizada pelo estudante.
* Técnicas: Controle de fluxo com switch-case, validação de intervalos, encerramento de execução (System.exit) e cálculos percentuais acumulados.
